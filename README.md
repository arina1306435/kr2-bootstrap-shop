# Контрольная работа №2 — Fluffy&Clean

**Тема:** CSS-фреймворки: разработка интерфейса на Bootstrap.

## Описание проекта
Учебный сайт эко-груминга для животных, разработанный с использованием CSS-фреймворка Bootstrap 5. Сайт включает главную страницу, каталог услуг, страницу о салоне и форму онлайн-записи.

## Используемые технологии
- HTML5
- Bootstrap 5 (подключение через CDN)
- Собственный CSS (`css/custom.css`)
- Git / GitHub

## Практическая работа №9
В рамках 9 практики выполнено:
- Создан новый проект `kr2-bootstrap-shop`.
- Подключен Bootstrap CSS и JS Bundle.
- Создана главная страница `index.html`.
- Добавлена навигация (компонент `navbar`).
- Добавлен hero-блок на сетке Bootstrap.
- Создан блок преимуществ с использованием `row` и `col-md-4`.
- Создана сетка популярных услуг с использованием `row` и `col-md-6`.
- Добавлен подвал страницы.

## Структура проекта
- `index.html` — главная страница
- `catalog.html` — услуги
- `about.html` — о нас
- `booking.html` — запись
- `css/custom.css` — кастомные стили
- `images/` — папка с изображениями
