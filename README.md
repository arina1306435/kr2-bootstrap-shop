# Контрольная работа №2

## Тема

«CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Используемый фреймворк

Bootstrap 5.

## Способ подключения

Bootstrap подключён через CDN. В блоке `head` каждого HTML-файла подключен CSS-файл фреймворка, а перед закрывающим тегом `body` — JS Bundle для работы интерактивных компонентов.

## Реализованные компоненты

- `navbar` (с выпадающим меню `dropdown`);
- `card`;
- `btn`;
- `badge`;
- `alert`;
- `modal`;
- `form-control`;
- `input-group`;
- `form-check`;
- `accordion`;
- `table`.

## Описание проекта

Учебный сайт эко-груминга для животных. Включает 4 страницы: главную, каталог услуг, страницу «О нас» и страницу онлайн-записи.

## Структура проекта

```text
kr2-bootstrap-shop/
├── index.html          — главная страница
├── catalog.html        — страница услуг
├── about.html          — страница о салоне
├── booking.html        — страница онлайн-записи
├── css/
│   └── custom.css      — кастомные стили
├── images/             — изображения
└── README.md
```

## Ссылка на GitHub Pages

https://arina1306435.github.io/kr2-bootstrap-shop/

## Самостоятельные доработки

1. Собственная визуальная концепция (Эко-стиль: оливковый, терракотовый, шалфейный).
2. Кастомная настройка Bootstrap в `custom.css` (скругления, тени, замена синего цвета на брендовый).
3. В форму записи добавлены дополнительные опции и модальное окно подтверждения.
